# PixelPasta – Project Brief

## Cel projektu
PixelPasta to zaawansowane narzędzie webowe do analizy, porównywania i raportowania plików LUT (.cube) wykorzystywanych w profesjonalnej produkcji filmowej. Projekt powstał z myślą o kolorystach, operatorach DIT i ekspertach postprodukcji, którzy potrzebują precyzyjnych narzędzi do kontroli transformacji barwnych i jakości LUT.

## Zakres
- Obsługa plików LUT 1D/3D (.cube)
- Analiza LUT względem referencyjnych krzywych (S-Log3, LogC4, Rec709, itp.)
- Interaktywne wykresy, tabele porównawcze, generowanie raportów PDF
- Minimalistyczny, ergonomiczny interfejs (dark mode, WCAG 2.1 AA)
- Integracja z biblioteką @21st-dev/magic
- Możliwość rozbudowy o funkcje kreatywne (morphing, VR, analiza wideo)

## Kluczowe wymagania
- Zgodność z dokumentacją producentów kamer (Sony, ARRI, RED, Canon)
- Precyzyjna interpolacja 1D/3D, analiza różnic (delta)
- Wysoka dostępność i responsywność UI
- System testów funkcjonalnych i matematycznych
- Możliwość eksportu wyników (PDF, CSV, ZIP)
- Skalowalność i łatwość wdrażania nowych funkcji
